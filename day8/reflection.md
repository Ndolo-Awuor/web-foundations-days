# Day 8 reflection

The most difficult part of this course for me was JavaScript fundamentals.
Understanding how variables, arrays, functions and events work together was
more challenging than writing the page structure or styling it. I used YouTube
tutorials to get different explanations of the concepts. They helped, but I am
still not fully confident, and I need more practice writing and explaining code
myself rather than only following a tutorial.

The feedback on my capstone was to improve further on what I already had.
Because that feedback was general, I would focus my next revision on clearer
explanations and more reliable error handling. In QuickNotes, I would explain
the difference between the practice API's simulated changes and a real service
that saves data permanently. I would also practise demonstrating loading,
validation, empty and error states, and explaining how the API, database and
architecture connect. This would help me present the project with more confidence.

Next, I intend to learn full-stack development. I will start by strengthening
JavaScript, especially functions, arrays, DOM events and asynchronous requests.
Then I want to learn how to build a backend API, connect it to a SQL database,
add authentication and test the complete application. My goal is to understand
each part well enough to build and troubleshoot projects more independently.
